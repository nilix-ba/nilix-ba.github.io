# Nilix BA - Personal Website

A minimal professional portfolio website built with Next.js and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deployment

This site is configured for deployment to GitHub Pages using the included workflow in `.github/workflows/nextjs.yml`.

## Technologies Used

- Next.js
- React
- Tailwind CSS
